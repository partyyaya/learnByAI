# 37｜面試準備與下一步成長路線

> 恭喜你完成整套課程。這章會幫你把學習成果轉成求職與職場可用的能力：作品集整理、面試準備、持續進階路線。

## 學習目標

- 能整理一份有說服力的 Python 作品集。
- 能準備技術面試常見題型與回答框架。
- 能制定 30/60/90 天成長計畫。
- 知道下一步往後端、資料或自動化深耕的方向。

## 前置條件

- 已完成至少 1 個專題（CLI/API/Data）。

## 作品集整理：先有可展示成果

建議至少準備 2 個專案：

- 一個工程向（CLI 或 API）
- 一個資料向（分析報告或爬蟲 + 視覺化）

每個專案都應包含：

- `README`（問題、解法、技術、啟動方式）
- 架構說明（模組分層）
- 測試與品質工具
- Demo 截圖或短影片（可選）

## README 面試友善模板

1. 專案背景與目標
2. 核心功能清單
3. 技術棧與選型理由
4. 快速啟動步驟
5. 測試方式
6. 後續可擴充方向

## 技術面試常見主題（Python）

### 語言基礎

- 可變/不可變物件
- list vs tuple vs set vs dict 使用時機
- `*args` / `**kwargs`
- 例外處理與除錯思路

### 工程實作

- 模組化與專案結構
- 測試策略（happy path + edge case）
- lint/format/type check
- Git 分支與 PR 工作流

### 後端方向

- HTTP 狀態碼與 REST 設計
- FastAPI 路由、驗證、錯誤處理
- DB CRUD、索引、交易

### 資料方向

- 缺失值處理策略
- 指標設計與圖表選型
- 分析結論如何避免過度推論

## 面試回答框架（STAR 技術版）

- **Situation**：場景
- **Task**：你要解決什麼
- **Action**：你做了什麼（技術與取捨）
- **Result**：結果與影響

範例：

```text
S：報表每週手動整理要 3 小時
T：希望自動化到 10 分鐘內完成
A：用 Python 寫 ETL 腳本，加入排程與錯誤通知
R：每週節省 2.5 小時，且錯誤率明顯降低
```

## 常見實作題準備建議

- 字串與陣列操作
- 字典統計與排序
- 檔案處理
- API 呼叫與資料轉換
- 簡單 SQL 查詢

練習原則：

- 先寫正確，再優化可讀性。
- 寫完用測試驗證邊界情況。

## 系統設計入門問題（Junior 常見）

- 如何設計一個 Todo API？
- 如何避免 API 重複建立資料？
- 如何處理失敗重試與 idempotency？
- 報表任務如何排程與監控？

回答時務必提到：

- 架構分層
- 錯誤處理
- 測試策略
- 可觀測性（logging/metrics）

## 履歷與自我介紹重點

- 用「問題 -> 行動 -> 結果」描述專題。
- 強調量化成果（時間節省、效能提升、準確率提升）。
- 不只列工具，重點是你如何解決問題。

## 30 / 60 / 90 天進階計畫

### 30 天（鞏固）

- 完成 1 個專題補齊測試與文件
- 每週解 3-5 題實作題
- 固定提交 GitHub（可見學習軌跡）

### 60 天（擴充）

- 再完成第 2 個不同類型專題
- 導入 Docker 與簡易部署
- 練習 3 次 mock interview

### 90 天（深化）

- 選定主線（後端 / 資料 / 自動化）深耕
- 研究一個進階主題（快取、訊息佇列、資料管線）
- 寫技術文章整理方法論

## 推薦持續學習方向

- 後端：FastAPI 進階、PostgreSQL、Redis、Docker、CI/CD
- 資料：Pandas 進階、SQL、統計基礎、BI 思維
- 自動化：排程平台、監控告警、流程可靠性設計

## 常見求職誤區

### 誤區 1：只背語法，不準備作品

修正：作品集是最有力證明。

### 誤區 2：只講技術，不講結果

修正：補上實際影響與量化數據。

### 誤區 3：忽略基礎工程習慣

修正：測試、文件、Git 流程一定要會。

## 最終檢查清單（求職前）

- [ ] 至少 2 個完整專題可展示
- [ ] 每個專題都有 README 與啟動步驟
- [ ] 至少 1 個專題有測試與 CI（或品質檢查流程）
- [ ] 可在 3 到 5 分鐘內清楚講完專題
- [ ] 準備好常見 Python / API / DB 問題

## 章末練習

- 必做：錄一段 3 分鐘專題自我介紹（可自己回看）。
- 必做：整理一份面試題清單並完成答案草稿。
- 選做：找同學或朋友做一次 mock interview。

## 本章重點回顧

- 學完課程只是起點，能展示與能溝通才是關鍵。
- 作品集 + 面試表達 + 持續迭代，三者缺一不可。
- 你已具備進入 Python 實務職場的完整起跑線。
