# 跟 AI 學習的課程

> 這是一個「跟 AI 一起學習」的技術知識倉庫，內容以章節化教材整理，從基礎觀念到實戰落地，幫你建立可持續進步的學習路線。

---

## 這個倉庫有什麼？

- 多條主題課程（演算法、TypeScript、Vue 源碼、Browser AI、PWA、Electron、Docker、Nginx）
- 每個主題都有獨立 `README` 與章節路線，適合循序學習
- 內容偏重「實作 + 心智模型」，不是只背指令或 API
- 可依需求走「完整路線」或「針對弱項補課」
