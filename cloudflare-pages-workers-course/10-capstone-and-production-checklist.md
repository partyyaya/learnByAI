# 10｜實戰專題與上線檢查清單

> 最後一章把前面所有內容整合成可交付專題，並用上線清單確保品質。

## 學習目標

- 能完成一個可部署、可監控、可迭代的完整專題。
- 能用檢查清單降低上線事故風險。
- 能產出可交接給團隊的技術文件。

## 專題範圍建議

- 前端：Pages 部署、Preview 流程、環境變數切分
- 後端：Workers API、至少一種儲存（D1/KV/R2）
- 自動化：CI/CD、部署後 smoke test
- 營運：監控儀表與告警閾值

## 上線檢查清單（MVP）

- 功能：核心流程 smoke test 全綠
- 效能：核心頁面達到團隊基準
- 安全：Secrets、權限、CORS、限流皆完成
- 可觀測：錯誤率與延遲可追蹤
- 回滾：有明確 SOP 並完成演練

## 專題交付物

- 架構圖與資料流圖
- CI/CD pipeline 說明
- 上線與回滾手冊
- 成本預估與優化計畫

## 結業挑戰

- 48 小時內完成一次「需求變更 -> 開發 -> Preview -> 合併 -> 上線」完整循環。
