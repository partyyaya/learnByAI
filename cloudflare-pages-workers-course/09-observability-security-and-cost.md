# 09｜監控、安全與成本管理

> 這章補齊上線後必備能力：可觀測性、安全控管與成本治理。

## 學習目標

- 能定義 API 與前端的核心營運指標。
- 能建立最小安全基線（Secrets、限流、驗證）。
- 能用監控資料追蹤與控制成本。

## 前置條件

- 已有基礎 CI/CD 與可部署版本。
- 團隊可存取 Cloudflare 監控面板。

## 核心觀念

- 沒有監控就沒有優化，沒有指標就沒有決策。
- 安全與成本不是最後補，而是每次迭代都要檢查。

## 優先監控指標

- 可用性：成功率、5xx 比例
- 延遲：P50/P95/P99
- 成本：請求趨勢、快取命中率、儲存成長
- 體驗：Web Vitals（LCP/CLS/INP）

## 安全基線

- 所有 Secrets 只存在平台環境變數，不進版控。
- API 設定速率限制與基礎驗證策略。
- 關鍵操作加上審計紀錄（誰在何時做了什麼）。

## 成本控管策略

- 建立每月預算與告警閾值。
- 優先優化高頻低命中的 API（加快取或改資料結構）。
- 將重計算轉為非同步流程（Queues）。

## 章末練習

- 必做：列出 5 個你要長期追蹤的指標與告警門檻。
- 選做：做一次成本回顧，提出 2 個優化實驗。
