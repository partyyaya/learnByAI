# algorithm 演算法課程

> 面向初學者到中階學習者的 LeetCode 解題課程。從資料結構操作、暴力解與複雜度開始，逐步練習選工具、證明不漏解，以及把想法寫成可執行的 TypeScript。

## 前置知識與範例約定

- 先熟悉變數、陣列、迴圈、函式與基本 TypeScript 型別；不要求已學過樹、圖或遞迴。
- `Map / Set`、節點參考與泛型比較器會在對應章節解釋。
- 範例以整數陣列與題目指定字元集為主；一般 Unicode 字串的差異見第 02 章。
- 複雜度會區分額外空間與輸出空間。雜湊操作採平均 O(1) 模型，動態陣列尾端操作採均攤 O(1) 模型。
- 各章程式區塊是獨立範例，不必把整份教材貼進同一個檔案。第 17 章會明確引用第 10 章的 Heap 與第 13 章的 DSU。

## 建議學習順序

第一次學習可依編號讀完 01–15，再選讀 16、17。順序刻意讓 Map 先於滑動視窗、遞迴先於回溯與 DP、Heap 先於 Dijkstra。

```text
01–05：線性資料與搜尋
  → 06–09：節點、狀態與遞迴搜尋
  → 10–13：候選選擇、貪心與圖
  → 14–15：重疊子問題與 DP
  → 16–17：選修延伸
```

若正在補弱項，可依表格的先備章節跳讀。例如學 DP 可以走 01、02、03、06、07、08、09、14、15；學最短路前，要先完成一般 BFS 與 Heap。

## 每章如何練習

每章題單依教學用途分為「暖身 → 核心 → 變形 → 挑戰」，不等同平台難度標籤。暖身題應在閱讀核心解答前先嘗試；挑戰題可以第二輪再做。

1. 讀題後先寫出輸入限制、暴力解與複雜度。
2. 手動追蹤一個小例子，說明資料結構裡每個值代表什麼。
3. 關掉解答自行實作，再檢查空輸入、單元素、重複值與極端順序。只測試題目契約允許的輸入。
4. 做一題變形，說明原方法何時不成立；不要只換變數名稱。
5. 完成章末自我檢查後，再前進到下一章。

## 階段驗收

| 完成階段 | 不看模板應能回答 |
|----------|------------------|
| 01–05 | 何時排序會破壞題意？為什麼含負數時某些視窗規則失效？二分到底保留哪個答案範圍？ |
| 06–09 | 改連結之前要保留什麼？遞迴函式回傳什麼？回溯哪些狀態要撤銷？ |
| 10–13 | Top K 為什麼用小根堆？貪心怎麼證明？何時用 BFS、拓撲或 DSU？ |
| 14–15 | 哪些歷史可以合併成同一狀態？容量為什麼正掃或倒掃？空間壓縮覆蓋了哪一層？ |

這份課程聚焦解題基礎與常見模型。Trie、字串匹配、Fenwick tree、線段樹、進階數論與更完整的排序分析可作後續專題，無須全部塞進第一輪。

從 [第 01 章](./01-foundations-complexity.md) 開始；程式操作不熟時，先反覆練習第 02 章的 Map、陣列複製與比較器。
