## 這份課程怎麼設計？

- **由淺入深**：先建立複雜度與資料結構直覺，再進到高頻題型。
- **題型導向**：每章集中講一種核心模型，幫你看到題目時快速聯想到工具。
- **白話推導**：不只給模板，會說明為什麼這樣做能從暴力降到更好的複雜度。
- **附 LeetCode 收尾題**：每章最後挑一題代表題，幫你把觀念落到實作。

## 適合對象

- 正在開始刷 LeetCode，常常不知道該從哪種題型開始的人
- 已經做過一些題，但對「為什麼這題要用這招」還不夠穩的人
- 準備面試，想快速重建高頻演算法主題地圖的人

## 建議學習順序

最推薦直接照章節順序學：

```text
01 基礎與複雜度
  -> 02 雙指標與滑動視窗
  -> 03 前綴和與雜湊表
  -> 04 堆疊、單調堆疊／佇列
  -> 05 二元搜尋與答案空間搜尋
  -> 06 樹與圖
  -> 07 動態規劃
  -> 08 選修：位元、貪心、進階圖
```

原因是前面幾章會一直反覆用到：

- 複雜度判斷
- 單調性
- 連續區間 vs 任意配對
- 狀態維護

這些都是後面章節的共同語言。

其中 `08` 是選修章節，建議在前面幾個核心題型都已有基本手感後再讀，吸收會比較順。

## 每章怎麼用最有效？

建議每章照這個節奏：

1. 先讀完章節概念，確認自己知道這類題在解什麼。
2. 手寫一遍章末的 LeetCode 題目，不直接看答案。
3. 做完後再補 2 到 3 題同家族題，強化辨識能力。
4. 回頭用自己的話總結：這類題的「觸發訊號」是什麼。

## 建議刷題方式

- **不要只記模板**：先理解這個技巧為什麼能縮小搜尋空間或避免重算。
- **先想暴力，再想優化**：這樣你才知道優化到底在省什麼。
- **整理自己的題型筆記**：把做過的題按「雙指標 / 前綴和 / 單調堆疊 / DP」分類，比按題號更有用。
- **同題多寫一次**：尤其是二分、圖、DP，第二次重寫時最能暴露邊界是否真的懂。
